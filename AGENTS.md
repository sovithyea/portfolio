# AGENTS.md

Instructions for AI agents live in [`CLAUDE.md`](CLAUDE.md). Read that file.

The short version, so you don't start on the wrong footing:

0. **Read `docs/PROGRESS.md` first.** It is the only current record of state.
1. **No application code before that phase's `specs/N-name/spec.md` and `plan.md` are reviewed by Vith.**
2. **Documentation is a lead, not evidence.** Read source or run it. Record what you observed in `docs/VERIFIED.md`.
3. **Never write a project fact from memory.** It comes from the project's repo, its live site, or Vith.
4. **Every picture is real:** a screenshot or demo of the actual project. No stock, no AI images. No private data in any picture.
5. **`docs/DESIGN-SYSTEM.md` is binding.** Tokens only; light and dark follow the system; no theme switcher.
6. **Conventional Commits 1.0.0**, with the why and `Refs:` footers. Nothing is pushed until Vith says. The repo is public.
7. **Write the least code that does the job well.**

Then read [`docs/WORKFLOW.md`](docs/WORKFLOW.md).
